# QRCode Scan

## 特性

### 二维码、条形码扫描并记录
- 支持多彩图标切换功能
- 二维码扫描保存功能全
- 条形码扫描保存功能全
- 数据导入导出功能齐全
- 多国语言切换功能支持
- 数据表格视图展示清晰
