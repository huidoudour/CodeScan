CodeScan 是一款功能强大的二维码和条形码扫描应用，采用先进的图像处理技术，支持多种格式的快速识别。所有数据本地处理，确保您的隐私安全。

快速扫描

使用先进的图像处理技术，快速识别各种二维码和条形码，支持多种格式包括QR码、Data Matrix、PDF417等。

高效处理

优化的算法确保在各种光照条件下都能准确识别，支持连续扫描和批量处理功能。

历史记录

自动保存扫描历史，方便您随时查看和管理之前的扫描结果，支持搜索和导出功能。

智能编辑

扫描后可直接编辑内容，支持复制、分享、保存等多种操作，满足不同使用场景需求。

隐私安全

所有数据本地处理，无需网络连接，确保您的隐私安全，扫描内容不会上传到任何服务器。

多平台支持

基于Android平台开发，适配各种设备尺寸，提供流畅的用户体验和现代化的界面设计。
